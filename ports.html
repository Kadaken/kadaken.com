Genesis3D Native Linux

Source available

A native 64-bit Linux runtime for the Genesis3D 1.x engine lineage. It combines preserved Eclipse/WildTangent engine code and later community maintenance with a Kadaken Linux frontend using SDL2 and OpenGL.

  • SDL2 window and input. Tested through X11/XWayland on Fedora.
  • BSP worlds. Textures, baked and runtime lightmaps, visibility, and swept-hull collision.
  • Animated ACT actors. Native 64-bit parsing, posing, and fixed-step motion playback.
  • Measured pacing. 60 and 120 FPS presentation verified on one AMD/Mesa system.
  • Public source. Distributed under the Genesis3D Public License v1.01.

This is presently a source-only engine runtime, not a game or a ready-made SDK release. No legacy game assets or compiled binary are distributed. Running it requires compatible assets you are legally entitled to use.
