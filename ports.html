Genesis3D Native Linux

Source available

A native 64-bit Linux runtime for the Genesis3D 1.x engine lineage. It combines preserved Eclipse/WildTangent engine code and later inherited source work with a Linux frontend built by Kadaken using SDL2 and OpenGL. No outside contributors to Kadaken's Linux port are claimed at this time.

  • SDL2 window and input. Tested through X11/XWayland on Fedora.
  • BSP worlds. Textures, baked and runtime lightmaps, visibility, and swept-hull collision.
  • Animated ACT actors. Native 64-bit parsing, posing, and fixed-step motion playback.
  • Measured pacing. 60 and 120 FPS presentation verified on one AMD/Mesa system.
  • Public source. Distributed under the Genesis3D Public License v1.01.

This is presently a source-only engine runtime, not a game or a ready-made SDK release. No legacy game assets or compiled binary are distributed. Running it requires compatible assets you are legally entitled to use.

Reality Factory Native Linux

Work in progress

A native 64-bit Linux port of the Reality Factory runtime, upstream 0.76.1. Reality Factory is the game creation kit built on top of Genesis3D, last released for Windows in 2009. It builds, links, opens a window and renders. It does not yet run a game end to end, and the gaps are published alongside the wins.

  • SDL2 host. Window, input and joystick, replacing the Win32 message loop and legacy DirectInput.
  • POSIX boundary. No Windows conditionals left in gameplay files.
  • Subsystems passing. Virtual file system, menus, GIF decoding, entity schemas and actor loading.
  • Sanitizer clean to stage four. One frame, queued quit, clean teardown, exit 0 under ASan and UBSan.
  • Every claim measured. Dated evidence for all of it in the repository's Reports directory.
View source on GitHub Join the community

Known gaps, stated plainly: stage five stops on its first tick at a missing previous-weapon guard, interactive launch has no mouse capture, thread safety is unproven pending ThreadSanitizer, and no visual equivalence testing against the original Windows renderer has been done. Test suites sit at 39 of 41.

Source only. No game assets and no compiled binary are distributed. Reality Factory is licensed under an MIT-form grant by Ralph Deane, 2002, which carries an added condition prohibiting its use for games that intentionally propagate genocide against a real group. That condition travels with this port unchanged.
