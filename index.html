Agent Workbench Native

Beta · Linux

One desk for the AI coding tools already on your machine. Projects on the left, your code in the middle, the agent on the right - and you watch it open files and work as it goes.

Tokens, cost and tool calls tick up while a turn runs, so you see what you are spending as you spend it.

  • Keeps its train of thought. Hand a full chat to a fresh one, context and all.
  • Watch it work. Files open and scroll to the line being changed.
  • Answers type out live. Not dumped at the end.
  • Built to be read. Seven fonts. Chat and code zoom separately.
  • 14 MB. Under 3% of one core sitting idle.
  • Yours alone. Your machine, your accounts, your disk.
  • Four assistants, one window. Claude, Codex, Gemini, Ollama.
  • Live counts. Tokens, cost and tool calls as the turn runs.
What it does not do yet
  • Linux x86-64 only. No Windows, macOS or ARM build.
  • Still in beta. Keep your projects in Git and keep backups.
  • Unrecognised command-line tools need setting up by hand.

CodeOp

Beta

A private room for playtesting with friends. Chat, share builds, jump on a call, share a screen, and break each other's games before anyone else does.

What it does not do yet
  • Brand-new Windows build — use headphones on calls for now.
  • Screen sharing works on Linux. It is not switched on for Windows in this build yet.
Download for Windows Zip · 27 MB · v4.0.0-beta+31 Download for Linux Portable · 22 MB · v4.0.0-beta+31 Report a problem

Windows: right-click the downloaded zip and choose "Extract All", open the extracted folder, then double-click "Install CodeOp.cmd". You get CodeOp in the Start Menu and on the Desktop. Linux: open it and it installs (Ubuntu, Debian, Mint, Pop!_OS).

If Windows blocks it: CodeOp is not code-signed yet, so Windows treats it as an unknown app.

  • "Windows protected your PC" - click More info, then Run anyway.
  • "Smart App Control blocked a file that may be unsafe", or a Bad Image error naming a .dll - that is Smart App Control, and it only runs apps signed by an authority it recognises. Marking the file as trusted does not help. The only ways past it are to turn Smart App Control off in Windows Security (App & browser control), which Windows will not let you undo without resetting the PC, or to wait for a signed build. Signing is being sorted out.

Genesis3D Linux

Source Available

A 1999 game engine, running natively on Linux again. Eclipse Entertainment published the full Genesis3D source under its own licence, WildTangent bought the assets that October and shipped version 1.1 in November, then abandoned it in place. Nothing was ever released after 1.1. This port takes that last version and replaces the Windows window, render, input and timing layers with SDL2 and OpenGL, then proves the physics still hold once all four are swapped out underneath it.

Assisted by Gemini and Codex Sol.

  • Native SDL2 input and rendering. X11/OpenGL for Linux.
  • Full BSP collision. Swept-hull detection with gravity, jumping, slopes.
  • Actor animation pipeline. Fixed 60 Hz simulation clock.
  • 60/120 FPS presentation. Configurable refresh rates.
  • Full source published. Under the Genesis3D Public License.
