One desk for the AI coding tools already installed on your Linux machine. Projects on the left, your code in the middle, the agent on the right — and you can watch it open files and work as it goes.

Tokens, cost and tool calls tick up while a turn runs, so you can see what you are spending as you spend it.

What it does not do yet
  • Linux x86-64 only. No Windows, macOS or ARM build.
  • This is a beta. Keep your projects in Git and keep backups.
  • Unknown command-line tools need setting up by hand.
