Agent Workbench Native

Public beta

One desk for the AI coding clients already installed on your Linux machine. Projects on the left, code in the middle, and the agent on the right — with live file activity as it works.

Verified beta downloads Source Free · open source · modern Linux x86-64

Watch the work happen

When an agent writes a file, the tree lights up, the file opens, and the text appears as it is being written — before it lands on disk. Touching several files at once splits the viewer: two side by side, three with one across the bottom, four in a grid.

Your installed clients, one place

AWBN automatically detects supported Claude Code, Codex, Gemini, and Ollama installations. Other local command-line clients can be added explicitly. Each chat keeps its own client, model, and effort setting.

Projects, not just chats

Register a folder and it becomes a project with its own chats, file tree and Run button. Loose chats stay in Conversations; project chats live in their project. Chats know which project they are in, so “open the config file” just works.

See what it costs, live

Tokens in, out, cache and tool spend tick upward while the turn runs, with a click-through list of exactly which tools were called. Provider usage limits are one glance away.

Edit alongside the agent

Unlock any file in the viewer and type. Saves keep local restore points, concurrent changes are detected before overwrite, and reverting shows a before/after diff. Keep Git history and backups as the durable recovery layer.

Built to be trusted

The bridge listens on localhost only, behind a token generated on your machine. Safe client modes are the default, protected credential paths are denied, silent global client updates are disabled, and beta updates are manual and checksummed.

Security model · Privacy

Install

  • AppImage — chmod +x, then run it.
  • .deb for Debian and Ubuntu.
  • Tarball with a per-user install script.

Needs Linux x86-64, Python 3.10+, and at least one agent CLI you already use.

Free, and staying free

Agent Workbench Native costs nothing and has no AWBN account, sync, advertising, or built-in telemetry. Provider CLIs, tools, custom clients, and update hosting remain governed by their own terms.

Beta honesty

This is early software for modern Linux x86-64. Keep projects in version control, maintain backups, review agent changes, and report reproducible problems with redacted diagnostics. macOS, Windows, and ARM builds are not available yet.
