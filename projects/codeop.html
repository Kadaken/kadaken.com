What it is

CodeOp is the temporary name for a lightweight social game-testing app. It is meant to replace the parts of Discord needed for small playtest groups: private chat, build/file sharing, voice, screen sharing, and remote help while testing Godot games.

Platforms

  • Windows, macOS, and Linux releases
  • Each button always uses the latest published build
