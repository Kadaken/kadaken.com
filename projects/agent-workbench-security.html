Security model

AWBN is a local launcher and workspace, not a sandbox around every AI client. A client can act within the operating-system and client permissions you grant it.

Local bridge

The bridge binds to loopback only and control routes require a random per-user token. App state is stored with user-only permissions. Foreign web origins are rejected.

Safe defaults

Codex defaults to workspace-write, Gemini uses its default approval mode, and bypass is an explicit unsafe choice. Protected credential paths are denied. Silent global client updates and unsigned in-place AWBN updates are disabled.

Untrusted extensions

Custom clients and MCP servers are executable code. Do not place secrets in a command string. Install only software you trust and review its own permissions and network behavior.

Beta limits

Keep projects in version control and backed up. Avoid simultaneous writers on the same uncommitted file. Verify downloads using the release's SHA256SUMS; checksums detect corruption but are not publisher code signing.

Report privately

Use the repository's private vulnerability report for security issues. Never include real credentials, private source code, or other people's data.
