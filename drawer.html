App drawer

Small tools, each built to solve one thing properly. They are not products; they are the things that were missing while building the products.

  • Subagent Viewer

    Alpha

    Watch an AI assistant's helpers work in real time: what they are reading, what they are running, what they are spending. Read-only, so it can never get in their way.

    Download for Linux Archive · 435 KB Report a problem

    Unpack it and run ./install.sh. Python and Tk only, both already on Fedora, so there is nothing else to fetch.

  • Auto Clicker

    Alpha

    A clicker for Fedora with nothing to install alongside it. Clicks where your pointer is, or around up to ten spots you mark. Hold right to start, tap right to stop.

    Download for Linux Archive · 114 KB Report a problem

    Unpack it and run ./install.sh. On Wayland it also runs ./setup-wayland.sh once, which asks for your password because moving the pointer needs a system permission.

  • AdCap Meter

    Alpha

    A floating bar for AdVenture Capitalist showing what you actually earn per second, minute, hour and day. Reads the game's own numbers, so it costs nothing to leave running.
